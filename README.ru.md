# AI Chat — локальный мульти-провайдер клиент

Чат с AI-моделями прямо в браузере: вставьте свой API-ключ — и общайтесь.
Без бэкенда, без облака, без регистрации: всё работает локально, ключ не покидает ваше устройство.

## Быстрый старт

Клиент — это три статических файла, сервер не нужен. Два способа запуска:

**Способ 1 — просто открыть файл:**

```bash
open index.html
```

**Способ 2 — локальный сервер (рекомендуется):**

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Первое подключение — 3 шага

1. **Выберите провайдера** на стартовом экране (или «Другой провайдер» для ручной настройки).
2. **Получите ключ** — ссылка «Где взять ключ →» под полем API Key ведёт на страницу создания ключа выбранного провайдера.
3. **Вставьте ключ и нажмите «Подключить»** — клиент проверит ключ, загрузит список моделей и откроет чат.

## Где взять ключ

| Провайдер | Где получить ключ |
|---|---|
| GitHub Models | https://github.com/settings/tokens (Personal Access Token с доступом к Models) |
| DeepSeek | https://platform.deepseek.com/api_keys |
| OpenRouter | https://openrouter.ai/keys |
| OpenAI | https://platform.openai.com/api-keys |
| Groq | https://console.groq.com/keys |

Любой OpenAI-совместимый endpoint тоже подойдёт (пункт «Другой (вручную)»): укажите название, URL endpoint и ключ.

## Безопасность

- **Ключ хранится только в localStorage вашего браузера** — он не отправляется никуда, кроме API выбранного провайдера.
- Серверного кода нет: запросы идут напрямую из браузера в API провайдера.
- Удалить ключ и все данные: **Настройки → «Удалить ключ и настройки»** (или очистите localStorage вручную).

## Возможности

- 6 провайдеров из коробки + любой OpenAI-совместимый endpoint
- Автоподбор лучшей модели из доступных
- Стриминг ответов с остановкой генерации
- История чата (сохраняется локально, до 100 сообщений)
- System prompt, temperature, max tokens
- Markdown-разметка и подсветка кода в ответах
- Тёмная тема, адаптив под мобильные

## Стек и структура

Чистые HTML/CSS/JS без зависимостей (кроме шрифтов Google Fonts):

```
index.html      — разметка
css/app.css     — стили, дизайн-токены
js/app.js       — вся логика (провайдеры, стриминг, настройки)
```
