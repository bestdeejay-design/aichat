# Support

AI Chat is a small local tool maintained in free time. Here's where to get help:

- **Docs**: read the [README](README.md) first — it covers setup, first
  connection and the provider key table.
- **Bugs and features**: [GitHub Issues](https://github.com/bestdeejay-design/aichat/issues)
- **Questions**: [GitHub Discussions](https://github.com/bestdeejay-design/aichat/discussions)

Before asking, check:

- The server is running (`python3 -m http.server 8080`) and you opened
  `http://localhost:8080`, not the raw file path
- The key is valid and the provider endpoint is reachable (see the error hint
  in the app: "Check the key and endpoint")
- Your provider allows CORS requests from browsers
